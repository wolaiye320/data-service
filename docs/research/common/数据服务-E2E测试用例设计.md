# 数据服务-E2E测试用例设计

## 1. 文档目的

本文档用于为 `data-service-web` 及管理端相关浏览器级测试生成 E2E 用例提供统一基线，确保页面验证不仅看见 UI，还能验证真实后端接口、状态流转和关键异常路径。

本文档属于“验收执行脚本基线”，重点回答页面怎么进、点哪里、输什么、看什么；本文仅维护最新测试跟踪结论，不记录逐次执行日志。

## 2. 编写依据

| 来源 | 用途 |
| --- | --- |
| `docs/research/common/数据服务-需求规格书.md` | 对齐页面功能范围、角色、验收标准和测试口径 |
| `docs/research/common/测试规范.md` | 约束 E2E 文档格式、首屏接口断言、稳定选择器和假绿防护 |
| `docs/research/common/UI设计规范.md` | 对齐页面主要交互区域与可见状态 |
| `docs/research/common/前端开发规范.md` | 对齐前端路由、页面职责和前后端交互约束 |

## 3. 适用边界

| 项目 | 说明 |
| --- | --- |
| 适用范围 | 浏览器级页面主流程、首屏数据加载、配置操作、发布操作、联邦平台主流程 |
| 默认工具 | Playwright |
| 默认环境 | 前端 `3001`、后端 `8081` |
| 不包含 | 纯接口测试、纯组件测试、一次性 UAT 记录 |
| 结果维护 | 执行结果写入 `docs/research/common/过程文档/` 的 E2E 报告 |

## 4. E2E 用例生成规则

### 4.1 必填字段

| 字段 | 要求 |
| --- | --- |
| 用例编号 | 采用 `E2E-{领域}-{序号}` |
| 页面入口 | 写明菜单进入路径和直接路由 |
| 前置条件 | 写明账号、角色、测试数据、服务状态、依赖接口 |
| 操作步骤 | 必须逐步写控件动作，不写“进行配置”“完成发布”这类空话 |
| 页面断言 | 必须写可见文本、标签状态、表格行、弹窗提示等可观察结果 |
| 接口断言 | 必须写至少 1 个关键接口及成功判定 |
| 实际结果 | 用于跟踪最新测试状态，统一写 `未执行 / 通过 / 失败 / 阻塞`，必要时补 1 句说明 |
| 自动化状态 | 统一写 `未自动化 / 部分自动化 / 已自动化` |
| 自动化脚本 | 标明 `spec 文件#用例标题` |
| 最近执行时间 | 记录最新一次有证据的执行日期，未执行填 `-` |
| 执行人 | 记录最新一次执行或确认结果的责任人，未知填 `-` |
| 证据/报告 | 记录对应测试报告、上线验证记录或脚本证据，未执行填 `-` |
| 备注/阻塞原因 | 记录阻塞原因、环境约束或补测说明，无则填 `-` |

### 4.2 强制规则

| 规则 | 说明 |
| --- | --- |
| 首屏成功断言 | 菜单页 / 首屏页必须同时断言关键接口成功返回 |
| 选择器稳定性 | 优先 `getByRole`、`aria-label`、`data-testid`，禁止依赖脆弱 class 和临时按钮文案 |
| 业务状态同步 | 长链路场景按保存成功、状态标签、日志 tab、发布结果等业务可见状态同步，不依赖 `networkidle` |
| 假绿防护 | 出现 console error、关键接口 `4xx/5xx`、全局错误提示默认判失败 |
| 覆盖边界 | 每个一级页面至少覆盖“正常主流程 + 1 条关键异常 / 限制路径” |
| 联邦闭环标记 | 联邦主流程只有覆盖预览执行、发布后统一查询、必要时重启复验，才能标记为完整闭环 |
| 环境差异 | 联邦相关页面至少覆盖 1 条非默认 schema / catalog 或真实数据库权限差异场景 |
| 报告收口 | 若存在 `skip`、`fixme`、临时放宽断言、降级路径，过程文档必须列出未覆盖项和风险项 |

### 4.3 推荐测试数据别名

| 别名 | 用途 |
| --- | --- |
| `admin_user` | 管理员登录身份 |
| `query_debug_demo_v2` | 查询调试页已发布演示服务 |
| `draft_service_demo` | 普通草稿服务 |
| `draft_federation_demo` | 联邦草稿服务 |
| `published_federation_demo` | 已发布联邦服务 |
| `catalog_ist` / `catalog_bes` | 非默认 schema / catalog 联邦来源 |
| `pg_conn_main` / `mysql_conn_main` / `oracle_conn_main` | 页面选择连接时的固定别名 |
| `restricted_query_user` | 受限角色或受限数据权限账号 |
