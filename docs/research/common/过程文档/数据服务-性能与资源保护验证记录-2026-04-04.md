## 6. 场景与结果

| 场景 | 对应用例 | 结果 | 结论 |
| --- | --- | --- | --- |
| 单次查询稳定完成 | `shouldExposeUnifiedQueryApi` | 通过 | 单次查询在基线资源下可稳定返回 |
| 重复请求缓存命中 | `shouldHitCacheWhenSameSingleQueryRepeats` | 通过 | 响应可识别缓存命中状态 |
| 批量查询稳定完成 | `shouldSupportBatchQuery` | 通过 | 批量结果可返回并保持输入顺序 |
| 批量结果与输入对应 | `shouldSupportBatchQuery` | 通过 | 每项结果包含 `index`、`params`、`rows` |
| 批量缓存命中统计 | `shouldExposePerItemCacheStatusForBatchQuery` | 通过 | 支持单项命中与总命中计数 |
| 批量规模超过服务限制 | `shouldRejectBatchQueryWhenBatchSizeExceedsServiceLimit` | 通过 | 返回 `400 PARAM_INVALID`，明确提示服务阈值 |
| 批量规模超过系统限制 | `shouldRejectBatchQueryWhenBatchSizeExceedsSystemLimit` | 通过 | 返回 `429 RESOURCE_LIMIT_EXCEEDED` |
| 服务未配置保护参数时回退系统默认值 | `shouldApplySystemDefaultsWhenServiceProtectionConfigMissing` | 通过 | 系统默认保护参数生效 |
| 结果集超过服务限制 | `shouldRejectSingleQueryWhenResultRowsExceedServiceLimit` | 通过 | 返回 `429 RESOURCE_LIMIT_EXCEEDED` |
| 结果集超过系统限制 | `shouldRejectSingleQueryWhenResultRowsExceedSystemLimit` | 通过 | 返回 `429 RESOURCE_LIMIT_EXCEEDED` |
| 服务超时阈值超过系统限制 | `shouldRejectQueryWhenServiceTimeoutExceedsSystemLimit` | 通过 | 返回 `408 QUERY_TIMEOUT` |
| 查询并发超过系统限制 | `shouldRejectConcurrentQueriesWhenSystemLimitIsReached` | 通过 | 返回 `429 RESOURCE_LIMIT_EXCEEDED`，实现受控并发 |
| 基础跨源组合查询成功 | `shouldSupportPredefinedCrossSourceQuery` | 通过 | 第一阶段基础跨源整合链路可稳定执行 |
| 同连接下推 Join 成功 | `shouldPreferDatabasePushdownWhenPredefinedJoinUsesSameConnection` | 通过 | 同连接场景优先下推，减少本地整合开销 |
| 联邦查询超时超过联邦系统限制 | `shouldRejectFederatedQueryWhenTimeoutExceedsFederatedSystemLimit` | 通过 | 联邦查询使用独立超时阈值，返回 `408 QUERY_TIMEOUT` |
| 联邦大结果集触发落盘缓冲摘要 | `shouldExposeSpillSummaryForLargeFederatedLookupResult` | 通过 | 返回 `previewRowCount`、`totalRowCount`、`spillTriggered`、`spilledRowCount`、`spillFile` |
| 联邦接口返回执行摘要字段 | `shouldSupportPredefinedCrossSourceQuery`、`shouldPreferDatabasePushdownWhenPredefinedJoinUsesSameConnection` | 通过 | 接口响应已稳定返回 `maxParallelism`、`stageWaveCount`、`executedStageCount`、`stageSummaries` |
| 联邦同波次阶段并发执行 | `shouldExecuteSameWaveStagesInParallelAndKeepDependentWaveOrdered` | 通过 | 同一波次内阶段可并发执行，依赖波次仍保持顺序执行 |
| 联邦阶段按真实依赖图切波 | `shouldSplitWaveByActualDependencyGraphInsteadOfDependencyCountOnly` | 通过 | 不再按“依赖数相同”错误并发，动态过滤值仅来自已完成上游阶段 |
