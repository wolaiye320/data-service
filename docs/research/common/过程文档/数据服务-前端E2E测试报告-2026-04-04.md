## 9. 风险与结论

| 项目 | 内容 |
| --- | --- |
| 已知约束 | 当前 E2E 已改为测试内自动创建连接、普通服务和联邦草稿，不再依赖固定演示服务 `query_debug_demo_v2` |
| 第二阶段约束 | 联邦平台 E2E 仍依赖本地 PostgreSQL 元数据库与真实后端可写环境 |
| 用例稳定性 | 联邦平台长链路已改为按业务可见状态同步，并取消对固定页签计数与 `networkidle` 的依赖，适配当前动态页面实现 |
| 三方噪音 | React 19 + antd 5 兼容 warning、`useForm` warning、Table `rowKey` deprecation 与循环引用提示已在 E2E 中过滤，不作为业务失败判定 |
| 不纳入项 | Oracle 容器验证不进入常规前端 E2E 回归命令 |
| 结论 | 当前仓库内可执行的 3 份前端 Playwright spec 已全部跑通，累计 8 条用例通过；剩余未完成项属于尚未实现自动化脚本的缓存、权限、多浏览器和大结果集交互场景 |
