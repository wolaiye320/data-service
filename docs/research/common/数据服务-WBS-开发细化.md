# 数据服务 WBS 开发细化

## 1. 文档目的

本文档基于《[数据服务 WBS 任务分解](/Volumes/osdisk/java_code/data-service/docs/research/common/数据服务-WBS.md)》《[数据服务需求规格书](/Volumes/osdisk/java_code/data-service/docs/research/common/数据服务-需求规格书.md)》和《[数据服务架构与详细设计](/Volumes/osdisk/java_code/data-service/docs/research/common/数据服务-架构与详细设计.md)》生成，用于将近期开发范围拆解到可分派、可编码、可测试的任务粒度。

本文档在既有 `M1 需求与设计冻结`、`M2 元数据模型完成`、`M3 SQL-first 保存发布闭环完成` 细化基础上，继续补充 `M4 查询执行闭环完成`、`M5 前端管理闭环完成`、`M6 测试闭环完成`、`M7 验收完成` 的任务粒度。所有新增任务初始状态均为“待开始”。

## 2. 状态说明

| 状态 | 含义 |
| --- | --- |
| 待开始 | 任务尚未进入实施，等待排期或分派 |
| 进行中 | 任务已进入实现或验证 |
| 已完成 | 任务实现、测试、文档同步均已完成 |
| 阻塞 | 任务因依赖、决策、环境或缺陷无法继续推进 |
