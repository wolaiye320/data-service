## 5. 风险与说明

| 项目 | 内容 |
| --- | --- |
| 串行口径 | 同一套 E2E 在默认 `4 workers` 并发模式下会把后端环境打挂，不适合作为正式功能验收口径；本次以 `--workers=1` 串行为准 |
| 后端启动方式 | `mvn spring-boot:run` 当前存在 `queryController` Bean 冲突，正式验收需使用前台 JAR 或修复冲突后再切回开发启动方式 |
| Oracle 说明 | Oracle 连接能力和测试表已具备，但当前浏览器级功能验收主要覆盖单源与联邦主链路，Oracle 深度执行仍留给后续非功能或专项验收 |
