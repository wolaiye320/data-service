| 项目 | 内容 |
| --- | --- |
| 后端集成测试基线 | `data-service-app` 当前无法通过定向 Spring 集成测试稳定复跑，根因是 `queryController` Bean 冲突与 app-only 测试依赖装配问题 |

| Oracle 深度验证 | 当前已确认 Oracle 环境、连接与基础数据可用，但未纳入本轮浏览器级串行主链路自动化，需作为专项回归继续补齐 |
