# 运行参数模板

## 后端默认参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `server.port` | `8081` | 后端默认端口 |
| `spring.profiles.default` | `local` | 默认环境 |
| `data-service.resource-protection.query-timeout-seconds` | `30` | 单次查询超时阈值 |
| `data-service.resource-protection.federated-query-timeout-seconds` | `60` | 联邦查询超时阈值 |
| `data-service.resource-protection.max-batch-size` | `100` | 系统级批量上限 |
| `data-service.resource-protection.max-result-rows` | `1000` | 系统级结果集上限 |
| `data-service.resource-protection.max-concurrent-queries` | `8` | 系统级并发查询上限 |

## 前端默认参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `dev server` | `3001` | 前端开发端口 |
| `preview server` | `3001` | 前端预览端口 |

## 启动示例

```bash
mvn -f data-service-app/pom.xml spring-boot:run -Dspring-boot.run.profiles=local
```

```bash
cd data-service-web && pnpm dev
```
