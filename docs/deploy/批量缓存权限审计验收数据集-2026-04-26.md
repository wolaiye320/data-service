## 2. 复用的基础服务形态

| 服务形态 | 基础 SQL | 作用 |
| --- | --- | --- |
| 单源查询服务 | `select id, order_name from public.orders where id = /* orderId */1` | 批量、缓存、查询权限、审计主样本 |
| 租户限定服务 | 在单源查询服务基础上设置 `tenantId='tenant-a'` | 租户越权与租户审计样本 |
| 预览服务 | 任一草稿服务即可 | 管理预览权限失败与 `ADMIN_ACCESS_DENIED` 审计样本 |

## 3. 批量验收输入数据

| 场景 | 输入 `inputs` | 预期用途 |
| --- | --- | --- |
| 批量全成功 | `[{\"params\":{\"orderId\":1}},{\"params\":{\"orderId\":2}}]` | 验证批量顺序、结果回填、`successCount=2` |
| 批量部分失败 | `[{\"params\":{\"orderId\":1}},{\"params\":{\"orderId\":\"bad\"}}]` | 验证部分成功、参数错误结构、`failureCount=1` |
| 批量超限 | 输入条数 `> maxBatchSize` | 验证批量资源保护错误结构 |

## 4. 缓存验收输入与上下文

| 场景 | 参数 / 上下文 | 预期用途 |
| --- | --- | --- |
| 首次命中前查询 | `orderId=1`，`callerId=cache-caller-a`，`traceId=cache-first-001` | 验证 `cacheHit=false` |
| 重复查询命中 | 同 `orderId=1`，同 `callerId`，新 `traceId=cache-second-001` | 验证 `cacheHit=true` |
| 上下文隔离 | 同 `orderId=1`，`callerId=cache-caller-b`，`contextKeys=['callerId']` | 验证不同调用方不复用缓存 |
| 策略变更后失效 | 保持 `orderId=1`，移除 `contextKeys` 或调整模板 | 验证缓存键变化与重新回填 |
| 显式清理后失效 | 清理服务缓存后再次查询 `orderId=1` | 验证 `cacheMissReason=EXPLICIT_EVICT` |

## 5. 权限验收输入

| 场景 | 输入 | 预期用途 |
| --- | --- | --- |
| 管理接口缺少管理员头 | 不传 `X-Operator` / `X-Operator-Role` 调用任一 `/api/admin/**` | 验证 `ACCESS_DENIED` 与 `ADMIN_ACCESS_DENIED` 审计 |
| 查询缺少 `callerId` | `requestContext={\"traceId\":\"auth-query-denied-001\"}` | 验证查询接口未授权错误 |
| 查询租户缺失 | 服务配置 `tenantId='tenant-a'`，请求只传 `callerId` | 验证“要求提供租户标识 tenantId” |
| 查询租户越权 | 服务配置 `tenantId='tenant-a'`，请求传 `tenantId='tenant-b'`、`callerId='tenant-caller-001'` | 验证越权拒绝与租户审计 |

## 6. 审计检索样本

| 审计事件 | 生成方式 | 建议检索键 | 预期用途 |
| --- | --- | --- | --- |
| `ADMIN_ACCESS_DENIED` | 预览或列表接口去掉管理员请求头 | `traceId=acc-preview-denied-001` | 审计页按 TraceId 检索权限失败 |
| `QUERY_TENANT_ACCESS_DENIED` | 租户限定服务以 `tenant-b` 查询 | `traceId=acc-tenant-denied-001` | 审计页查看租户失败详情与上下文摘要 |
| `QUERY_EXECUTE` | 正常单源或联邦查询 | `traceId=acc-query-success-001` | 审计页查看正式查询成功记录 |
| `PREVIEW_SERVICE` | 管理员身份执行一次草稿预览 | `eventType=PREVIEW_SERVICE` + `serviceCode` | 验证预览审计可检索 |

## 7. 建议固定值

| 项目 | 建议值 | 说明 |
| --- | --- | --- |
| 批量调用方 | `batch-caller-001` | 批量成功 / 部分失败均可复用 |
| 缓存调用方 A | `cache-caller-a` | 验证首次查询与重复命中 |
| 缓存调用方 B | `cache-caller-b` | 验证上下文隔离 |
| 租户服务租户 | `tenant-a` | 服务侧固定租户 |
| 越权租户 | `tenant-b` | 请求侧错误租户 |
| 预览拒绝 TraceId | `acc-preview-denied-001` | 便于审计页定位 |
| 租户拒绝 TraceId | `acc-tenant-denied-001` | 便于审计页定位 |

## 10. 风险与说明

| 项目 | 内容 |
| --- | --- |
| TraceId 约定 | 文档中的 TraceId 是建议固定值，正式执行时可替换，但必须保证审计检索键唯一 |
| 服务前置 | 批量、缓存、租户场景都依赖先创建对应服务；服务 SQL 与基础表请复用 `14.2.1` 文档，不要现场临时改 SQL |
| 审计污染 | 当前环境审计日志较多，执行验收时必须以 `traceId` 或 `serviceCode + eventType` 组合检索，避免读到旧记录 |
