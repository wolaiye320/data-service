# 多数据库联邦验收环境清单-2026-04-26

## 1. 范围与目标

| 项目 | 内容 |
| --- | --- |
| 对应 WBS | `14.1.2` 准备多数据库联邦验收环境 |
| 目标 | 确认 PostgreSQL、MySQL、Oracle 三类数据源均具备联邦验收所需的连接入口、测试账号和基础测试对象 |
| 覆盖范围 | PostgreSQL 联邦业务库、MySQL 联邦业务库、Oracle 测试容器与测试 Schema |
| 不含范围 | 复杂表达式与跨库联邦用例数据编排，留给 `14.2.*` 处理 |

## 8. 风险与说明

| 项目 | 内容 |
| --- | --- |
| 凭据管理 | 本清单只确认账号来源存在，不在文档中明文记录密码 |
| PostgreSQL 样本边界 | 当前联邦业务库测试对象为 `fed_test_customer`，不是本地元数据库中的 `orders` 表，后续验收数据设计必须按真实库对象组织 |
| Oracle 边界 | 当前已确认 Oracle 容器和测试表可读，但后续若要纳入常规自动化回归，仍需单独评估执行时长与环境稳定性 |
