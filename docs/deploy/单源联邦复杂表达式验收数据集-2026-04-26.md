## 7. 建议验收 SQL

| 场景 | 建议 SQL | 预期样本 |
| --- | --- | --- |
| 单源 PostgreSQL | `select id, order_name from public.orders where id = /* orderId */1` | `1 -> order-a` |
| 同构 PostgreSQL 联邦 | `select o.id as order_id, oi.sku as item_sku from PG_MAIN@public.orders o join PG_ARCHIVE@public.order_items oi on o.id = oi.order_id where o.id = /* orderId */1` | `1 -> sku-a` |
| 单源 PostgreSQL 联邦业务库 | `select customer_id, customer_name, region from postg_federation1.fed_test_customer where customer_id = /* customerId */1001` | `1001 -> Alice Zhang / EAST` |
| 单源 MySQL | `select order_id, product_name, amount from mysql_federation1.fed_test_order where order_id = /* orderId */20001` | `20001 -> Risk Scanner / 1200.00` |
| 异构 PostgreSQL + MySQL 联邦 | `select c.customer_code, c.customer_name, o.product_name, o.amount from PG_BIZ@postg_federation1.fed_test_customer c join MY_BIZ@mysql_federation1.fed_test_order o on c.customer_code = o.customer_code where c.customer_code = /* customerCode */'C1001'` | `C1001 -> Alice Zhang + 2 条订单` |
| 单源 Oracle | `select id, order_name from ORACLE_MAIN@ORACLE_TEST.orders where id = /* orderId */20001` | `20001 -> oracle-order-a` |

## 8. 复杂表达式建议

| 表达式类型 | 建议 SQL 片段 | 对应样本 | 预期 |
| --- | --- | --- | --- |
| 字符串拼接 | `concat(order_name, '-x') as order_label` | PostgreSQL `order-a` / Oracle `oracle-order-a` | 返回 `order-a-x`、`oracle-order-a-x` 等 |
| CASE | `case when amount >= 1000 then 'HIGH' else 'NORMAL' end as amount_level` | MySQL `1200.00`、`800.00` | 同时覆盖 `HIGH` / `NORMAL` |
| 聚合 | `count(*) as total_count` | PostgreSQL `orders` + `order_items` | 同构 Join 后 `order_id=1` 计数为 `1` |
| 日期时间 | `created_at` 直接投影或按日期过滤 | PostgreSQL 联邦客户、MySQL 订单 | 验证时间字段读写与格式保持 |
| 多字段投影 | `customer_name`, `region`, `credit_rating`, `product_name` | PostgreSQL + MySQL 联邦 | 验证联邦字段顺序与别名 |

## 10. 风险与说明

| 项目 | 内容 |
| --- | --- |
| 连接编码占位 | 建议 SQL 中的 `PG_MAIN`、`PG_ARCHIVE`、`PG_BIZ`、`MY_BIZ`、`ORACLE_MAIN` 是验收连接示例名，执行前应替换成环境中实际连接编码 |
| Oracle 连接路径 | 当前 Oracle 容器已验证 `xepdb1` / `ORACLE_TEST.orders` 可读，若验收时切到其他 service name，需同步改连接配置 |
| 跨库键选择 | 异构联邦建议优先使用 `customer_code`，不要再沿用本地 `orders.id` 与 MySQL 订单的偶发对齐值作为长期验收主键 |
