## 7. 回退方案

### 7.1 回退触发条件

| 条件 | 处理 |
| --- | --- |
| 联邦平台页面无法加载 | 回退前端静态包，必要时同时回退后端 |
| 联邦 SQL 保存 / 发布失败 | 回退后端版本并保留元数据库日志与校验记录 |
| 联邦统一查询主链路失败 | 回退后端版本并保留问题现场日志 |
| 联邦执行摘要缺失或结构异常 | 回退后端版本，避免上线后诊断口径失真 |

### 7.2 回退步骤

| 步骤 | 操作 |
| --- | --- |
| 1 | 停止当前发布实例 |
| 2 | 恢复上一版后端 JAR |
| 3 | 恢复上一版前端静态产物 |
| 4 | 重新启动后端与前端发布实例 |
| 5 | 复核 `GET /actuator/health`、`GET /api/platform/baseline` |
| 6 | 使用一个已发布联邦服务执行最小联邦查询冒烟 |

### 7.3 数据回退原则

| 项目 | 原则 |
| --- | --- |
| Flyway 已执行但业务异常 | 不直接手工改表，优先按新版本补救迁移或恢复数据库备份 |
| 联邦 SQL 草稿 / 版本 | 优先保留问题现场；若需回退元数据，仅删除本次变更的服务版本快照 |
| 校验日志与计划产物 | 作为问题定位依据默认保留，不作为回退清理对象 |
